# 셸 프로그래밍 보고서

교수님 제출 형식은 `셸프로그래밍(학번,이름).docx`이다. 보고서에는 각 문제별 실제 우분투 실행 화면과 소스코드가 모두 포함되어야 한다.

**보고서 DOCX의 GitHub 업로드는 아직 완료되지 않았다.** 로컬에서 준비한 DOCX를 최종 캡처로 수정한 다음 이 폴더에 업로드한다. ZIP이나 PDF만 올리는 것은 교수님이 요구한 DOCX 제출을 대체하지 않는다.

보고서와 저장소의 소스코드는 동일한 버전으로 맞춰야 한다. 특히 `ex3-4.sh`는 4.5 만점 GPA로 변경되었으므로 이전 4.0 GPA 캡처를 교체하고, `ex3-9.sh`는 부분 문자열 검색을 지원하도록 변경되었으므로 실제 검색 시연을 다시 촬영한다.

`tools/demo.sh`는 자동화된 동작 확인용이며, 일부 문제는 메뉴 전체를 생략한 요약 출력만 보여 준다. 대화형 메뉴(4번과 5번)는 `sh src/ex3-4.sh` 및 `sh src/ex3-5.sh`를 직접 실행해 메뉴와 입력 흐름이 모두 보이는 화면으로 캡처하는 것을 권장한다.
