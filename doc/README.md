# 실습 보고서 (DOCX)

최종 제출 파일은 `셸프로그래밍(20261680,김이안).docx`이다. 이 `doc/` 폴더는 교수님이 요구한 보고서 저장 위치다.

현재 DOCX는 **재촬영용 작업본**으로 별도로 준비되어 있으며, 실제 우분투 터미널에서 새로 촬영한 0~9번 스크린샷을 교체한 뒤 최종본을 업로드할 예정이다. 이 폴더에 아직 DOCX 파일이 없다는 것은 최종 제출이 완료되지 않았다는 뜻이다.

## 입력 및 캡처 방법

`src/ex3-2.sh`와 `src/ex3-3.sh`는 한 줄에 값을 몰아 넣지 않고 한 번에 하나씩 직접 입력한다. `src/ex3-4.sh`와 `src/ex3-5.sh`는 기존부터 메뉴 선택을 차례로 입력받는다. `tools/demo.sh`의 자동 입력 방식은 제거했고, 단일 스크립트의 실제 대화형 실행만 지원한다.

실행 중 만들어진 메뉴·프롬프트와 사용자가 실제로 입력한 값이 보이는 **실제 터미널 화면**을 캡처한다. 자동으로 입력한 화면을 직접 입력한 것처럼 보정하지 않는다. 캡처 완료 후 코드를 포함하는 DOCX 보고서를 `doc/`에 업로드하고 수업 게시판에는 지정된 DOCX 형식으로 제출한다.

GPA는 교수님이 환산표를 제시하지 않아 임시 예시인 4.5 만점 기준을 사용한다. 부분 이름 검색을 포함해 9번 코드를 수정했으므로 보고서에는 새 코드에서 실행한 결과를 넣는다.
