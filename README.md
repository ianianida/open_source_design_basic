# 오픈소스기초설계 셸 프로그래밍 실습

우분투에서 실행하는 셸 스크립트 10개를 `src/`에 보관한다. 각 문제의 코드와 실제 실행 화면을 포함한 보고서는 `doc/`에 보관한다.

현재 스크립트는 초안이며, 우분투 가상 머신에서의 최종 실행 확인과 보고서 작성이 남아 있다.

## 실행 방법

저장소 최상위 폴더를 기준으로 실행한다.

```sh
sh src/ex3-0.sh
sh src/ex3-1.sh 12 5
sh src/ex3-2.sh
sh src/ex3-3.sh
sh src/ex3-4.sh
sh src/ex3-5.sh
sh src/ex3-5.sh -l src
sh src/ex3-6.sh files
sh src/ex3-7.sh links
sh src/ex3-8.sh Alice 2001-01-01
sh src/ex3-9.sh Alice
```

`ex3-0.sh`는 `~/.bashrc`에 `MYENV`를 등록한다. 기존에 다른 값의 `MYENV`가 설정되어 있으면 수정하지 않고 중단한다. `unset`은 해당 셸에만 적용되며 새 Bash를 실행하면 `.bashrc`의 등록값이 다시 적용된다.

`ex3-6.sh`와 `ex3-7.sh`는 지정한 폴더 안에 고유한 실습 폴더를 만들어 기존 파일을 덮어쓰지 않는다. `ex3-8.sh`와 `ex3-9.sh`는 현재 작업 디렉터리의 `DB.txt`를 함께 사용한다. `ex3-8.sh --new 이름 정보`는 기존 DB가 있으면 확인을 받은 뒤 새로 쓴다.

예시 입력으로 열 문제를 차례로 확인하려면 `sh tools/demo.sh`를 실행한다. 문제마다 20초씩 결과를 표시하며 테스트 파일은 임시 폴더에 생성한다. 다만 0번은 요구사항에 따라 사용자 `~/.bashrc`에 환경변수를 등록한다.

## 확인이 필요한 과제 조건

- PDF 4쪽과 5쪽의 두 요구사항이 모두 `ex3-5.sh`로 표기되어 있어 시스템 상태 메뉴와 함수의 `ls` 인자 전달을 하나의 파일에 포함했다. 교수님 확인이 필요한 해석이다.
- PDF에는 `ex3-4.sh`의 GPA 환산 기준이 명시되어 있지 않다. 이 구현은 평균 점수에 적용하는 **임시 예시 4.0 만점 기준**을 표시한다. 교수님 기준이 확인되면 수정한다.
